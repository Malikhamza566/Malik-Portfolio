04 / How I work

Design, build, ship.

  1. Design

    Start in Figma or Google Stitch. Map the roles, screens and data before writing code, then sketch the HLD and LLD.

  2. Build

    Reusable components on the front, clean REST APIs and auth on the back. Code reviews and sprints keep it honest.

  3. Ship

    Test, integrate and deploy to Firebase, Netlify, Railway or Render, with Docker and environment config where it counts.
